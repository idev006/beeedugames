# RG-02: AR Device Acceptance

สถานะผ่าน Gate นี้ต้องมาจากการทดสอบด้วยมือจริง ไม่ใช่เพียง unit test หรือการเปิดกล้องสำเร็จ

## อุปกรณ์ขั้นต่ำ

| กลุ่ม | ตัวแทนที่ต้องทดสอบ | ผล |
|---|---|---|
| Desktop | Windows + Chrome/Edge + webcam | Pending |
| Android | โทรศัพท์ Chrome กล้องหน้า | Pending |
| Tablet | Android tablet Chrome หรือ iPad Safari | Pending |

## ขั้นตอนต่ออุปกรณ์

1. เปิดเกมผ่าน HTTPS หรือ localhost และเริ่มแบบ AR
2. อนุญาตกล้อง ตรวจว่า video ไม่กลับซ้ายขวาผิดจาก pointer
3. ให้เห็นมือตั้งแต่ปลายนิ้วถึงข้อมือ พร้อมแสงด้านหน้า
4. ตรวจแผง `ตรวจระบบ AR` ตามลำดับ: กล้อง → มือ → นิ้วชี้ → pointer
5. ชี้กลางวัตถุจน dwell ครบ และตรวจว่า `เลือกวัตถุได้` เปลี่ยนเป็นสีเขียว
6. ลากผ่านแท่งพลังหลายแท่ง และทดลองคันโยกชาร์จทั้งหมด
7. ตอบถูก/ผิดอย่างละหนึ่งครั้ง ตรวจว่า pointer ถูกพักนอกตัวเลือกก่อนโจทย์ใหม่
8. เล่นต่อเนื่อง 5 นาที ตรวจว่าไม่มี flicker, navigation กลับหน้าแรก, WebGL crash หรือ input lag เกิน 250 ms
9. ปิด AR และยืนยันว่าเมาส์/สัมผัสยังเล่นต่อได้

## เกณฑ์ผ่าน

- ทุกขั้นผ่านบนอุปกรณ์ทั้งสามกลุ่ม
- การเลือกสำเร็จอย่างน้อย 10 ครั้งต่ออุปกรณ์ โดยไม่เลือกผิดจาก pointer drift
- ไม่มี blocker ใน console; warning ของ MediaPipe ที่ไม่กระทบผลต้องบันทึกแยก
- ถ้าอุปกรณ์ใดไม่ผ่าน ให้ RG-02 เป็น `No-Go` พร้อมรุ่นอุปกรณ์/OS/browser/ข้อความผิดพลาด
