# UI/UX Specification

## หลักการจัดพื้นที่

- ฉากเล่นเป็นพื้นที่หลักและคง aspect ratio ที่เหมาะกับ artwork
- HUD อยู่ในแผงด้านข้างบน desktop เพื่อลดการบีบฉาก
- บนจอแคบ HUD ย้ายเป็น bottom sheet แบบยุบได้ ไม่ซ้อนทับจุดเล่น
- ใช้ `min-height: 100dvh` และ internal scroll เฉพาะ panel ที่จำเป็น ไม่สร้าง page scrollbar โดยไม่ตั้งใจ
- ทุก state มีทางไปต่อชัดเจน: เล่นต่อ, ลองใหม่, กลับแผนที่, ตั้งค่า

## หน้าจอหลัก

1. **Home**: เลือกบท/เขต/โหมด และเห็นการซ่อมเมืองที่ทำไปแล้ว
2. **Map**: เลือกเขตแม่คูณ 2–25 พร้อมสถานะ mastery
3. **Game**: ฉากใหญ่ + side HUD; mission text เป็นภาษาธรรมชาติ
4. **Pause/Settings**: drawer ขนาดพอดีจอ มี range slider, dropdown และ toggle
5. **Result**: แสดงสิ่งที่ซ่อมได้ คู่คูณที่คล่อง และภารกิจถัดไป

## Feedback

ถูก: แสงวิ่งตามสายพลังงาน, กลุ่มล็อกเข้าที่, มีประกายสั้น ๆ และข้อความเชิงกำลังใจ

ผิด: ชิ้นส่วนเด้งกลับอย่างนุ่มนวล, แสดงจุดที่ขาด/เกิน, ให้ action แก้ไขทันที ไม่ใช้เอฟเฟกต์ลงโทษรุนแรง

## Interaction requirements

- hit area ขั้นต่ำ 44px
- keyboard focus มองเห็นได้
- motion effects ปิดได้
- ใช้ไอคอนร่วมกับข้อความ ไม่พึ่งสีอย่างเดียว
