# Game Story

## ชื่อเรื่อง

**เมืองแสงซ่อนกล: ทีมช่างพลังคูณ**

## Premise

เมืองลูมินาราเคยส่องสว่างด้วย “แกนแสง” ที่ทำงานจากกลุ่มพลังงานเท่ากัน แต่หมอกลวงตาทำให้กลุ่มพลังงานแตกกระจาย เครื่องจักรจึงหยุดทำงาน ผู้เล่นได้รับตราช่างฝึกหัดและออกเดินทางซ่อมเขตต่าง ๆ ด้วยการจัดกลุ่มพลังงานให้พอดี

## ตัวละครใหม่

- **ลูมิน** นักประดิษฐ์จิ้งจอก ผู้ลงมือทำภารกิจและเป็น avatar ของผู้เล่น
- **พิกซ์** หุ่นลูกบาศก์ลอยได้ แปลงจำนวนให้เห็นเป็นกลุ่ม แถว และช่อง
- **มารุ** ตัวนิ่มขนส่งของ ช่วยนำชิ้นส่วนไปเติมเครื่องจักร
- **เซน** นกฮูกนักทำแผนที่ เปิดเขตใหม่และบันทึกความก้าวหน้า
- **เงาลวง** ปรากฏการณ์ของหมอก ไม่ใช่ผู้ร้ายที่ต้องกำจัด แต่เป็นความสับสนที่ต้องคลี่คลายด้วยหลักฐาน

รายละเอียดรูปลักษณ์ยังเป็น placeholder จนกว่าจะได้รับ Character Bible จากผู้ใช้

## เส้นเรื่อง 5 บท

1. **ประตูเมือง**: เรียนรู้การมองจำนวนเป็นกลุ่มเล็ก ๆ และซ่อมไฟแม่ 2–5
2. **ตลาดลอยฟ้า**: เติมสินค้าเป็นแถวและเปิดเส้นทางแม่ 6–10
3. **โรงงานเฟืองดาว**: จัดชิ้นส่วนหลายชุดและสลับมุมมองแม่ 11–15
4. **หอคอยหมอก**: แก้เส้นทางที่มีตัวลวงและทบทวนแม่ 16–20
5. **แกนแสงกลางเมือง**: รวมพลังทุกเขตและท้าทายแม่ 21–25

## แรงจูงใจให้เล่นต่อ

- ทุกภารกิจซ่อมส่วนหนึ่งของเมืองให้เปลี่ยนแปลงอย่างเห็นได้ชัด
- ทุก 4 จุดซ่อมสำเร็จ สมาชิกใหม่จะเข้าร่วมทีมพร้อมแนะนำบทบาท ก่อนเปิดเขตถัดไป เด็กจึงเห็นว่าตัวละครและฉากใหม่เป็นรางวัลจากความก้าวหน้าของตน
- ได้สะสมชิ้นส่วนเครื่องจักรและตราความชำนาญ ไม่ใช่แค่ตัวเลขคะแนน
- ปลดล็อกบทสนทนา แผนที่ และรูปแบบการจัดกลุ่มใหม่
- ระบบ “สัญญาณเตือน” จะพาผู้เล่นกลับไปทบทวนคู่คูณที่ยังไม่คล่อง
- ความสำเร็จมีหลายแบบ: แม่นยำ, อธิบายได้, รักษาพลังงาน, และช่วยเพื่อน

## โทน

อบอุ่น ผจญภัย ฉลาด ร่าเริง มีความลึกลับเล็กน้อย และให้เด็กเป็นผู้แก้ปัญหา ไม่ใช่ผู้ถูกสอบ
