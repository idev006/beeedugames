# Learning Design

## ความรู้หลัก

ครอบคลุมแม่คูณ 2–25 และตัวคูณ 1–12 โดยเน้นความหมายของการคูณก่อนความเร็วในการจำ

## การแปลงคณิตศาสตร์เป็นการเล่น

| ความรู้ | การกระทำในเกม | หลักฐานความเข้าใจ |
|---|---|---|
| กลุ่มเท่ากัน | ลากพลังงานลงรถขนส่ง | จำนวนในแต่ละกลุ่มเท่ากัน |
| แถวและคอลัมน์ | หมุนแผงไฟให้เป็นตาราง | เห็นจำนวนแถว × จำนวนต่อแถว |
| ผลคูณ | เชื่อมสายพลังงานไปยังแกนแสง | แกนติดเมื่อจำนวนรวมพอดี |
| การตรวจคำตอบ | เลือกชิ้นส่วนที่ทำให้เครื่องสมดุล | อธิบายได้ว่าขาด/เกินเท่าไร |

## Mastery model

เก็บผลแบบแยก `table` และ `multiplier` โดยดู 3 แกน: accuracy, response time, representation. ผ่านระดับเมื่อมีความถูกต้องต่อเนื่องและแสดงวิธีคิดได้ ไม่ใช้ความเร็วอย่างเดียวตัดสิน

## Adaptive practice

- ทุกภารกิจสุ่มจำนวนสถานการณ์ แต่ต้องมีเป้าหมายที่เรียนรู้อยู่เสมอ
- ผสมข้อที่คล่องแล้วกับข้อที่ยังผิดในสัดส่วนที่เหมาะสม
- หลังผิด แสดงกลุ่มพลังงานให้เห็นและให้ลองแก้ใหม่โดยไม่หักความก้าวหน้าทั้งหมด
- ใช้ distractor จากข้อผิดพลาดจริง เช่น ลืมจำนวนกลุ่ม หรือบวกแทนคูณ

## Accessibility

รองรับเมาส์ คีย์บอร์ด และ touch; สีไม่ใช่สัญญาณเดียว; มี reduced motion; ไม่มีเสียงเป็นเงื่อนไข; ตัวอักษรไทยต้องอ่านง่ายและปรับขนาดได้
