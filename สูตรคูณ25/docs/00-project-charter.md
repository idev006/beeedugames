# Project Charter

## ชื่อโครงการ

สูตรคูณ 25: เมืองแสงซ่อนกล

## วิสัยทัศน์

ทำให้เด็กค้นพบว่า “การคูณคือการจัดกลุ่มอย่างฉลาด” ผ่านการช่วยชุมชนในเมืองแฟนตาซี ไม่ใช้หน้าตาเกมแบบข้อสอบเป็นศูนย์กลาง

## กลุ่มเป้าหมาย

เด็กประถมที่กำลังเรียนหรือทบทวนการคูณ ครู/ผู้ปกครองที่ต้องการกิจกรรมฝึกซ้ำแบบมีความหมาย และผู้เรียนที่มีความเร็วในการคำนวณต่างกัน

## เป้าหมายการเรียนรู้

เมื่อเล่นจบช่วงหนึ่ง ผู้เล่นควรสามารถ:

1. สร้างภาพในใจของการคูณจากกลุ่มที่เท่ากัน
2. จำผลคูณที่ใช้บ่อยได้เร็วขึ้น
3. อธิบายหรือพิสูจน์คำตอบด้วยการนับกลุ่ม/แถว/ช่อง
4. สังเกตข้อผิดพลาดของตนเองและลองใหม่โดยไม่กลัวผิด

## หลักการออกแบบ

- Gameplay first, math embedded: คณิตศาสตร์อยู่ใน action ของเกม
- Feedback ชัดแต่ไม่ตีตรา: ผิดคือข้อมูลสำหรับการเรียนรู้
- ความยากเพิ่มทีละขั้นและมีการทบทวนแบบเว้นระยะ
- ผู้เล่นมี agency เลือกเส้นทางและรูปแบบภารกิจ
- ตัวละครทั้งหมดเป็นชุดใหม่ ไม่ใช้กัปตันอ่างน้อยหรือทรัพยากรจากเกมเดิม

## ตัวชี้วัดความสำเร็จ

- ความถูกต้องรายแม่คูณและรายตัวคูณ
- เวลาตอบสนอง median ไม่ใช่คะแนนสูงสุดเพียงอย่างเดียว
- อัตราการกลับมาทบทวนโจทย์ที่เคยผิด
- ผู้เล่นสามารถอธิบายวิธีคิดได้จากภาพกลุ่ม
- ไม่มี soft-lock เมื่อหมดชุดภารกิจหรือกดผิดติดกัน

## นอกขอบเขตระยะ MVP

- ระบบแข่งขันออนไลน์และ leaderboard
- การซื้อขายเงินจริง
- 3D เต็มรูปแบบ
- การบังคับใช้เสียงพูดหรือกล้องเป็นเงื่อนไขการเล่น
