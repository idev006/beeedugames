# Gameplay Loop

## Core loop

```text
รับภารกิจจากเขตเมือง
  -> สำรวจฉากและอ่านสัญญาณจากเครื่องจักร
  -> จัดกลุ่ม/ลาก/หมุน/เชื่อมพลังงาน
  -> เห็นผลลัพธ์เป็นภาพและได้รับ feedback
  -> ซ่อมสำเร็จหรือแก้จากคำใบ้
  -> รับชิ้นส่วนและเปิดพื้นที่ถัดไป
```

## Session flow

1. เลือกเขตหรือภารกิจที่เปิดแล้ว
2. ระบบสร้างสถานการณ์จากแม่คูณและตัวคูณที่กำหนด
3. ผู้เล่นลงมือแก้ปัญหาผ่านฉาก ไม่แสดงโจทย์แบบ worksheet เป็นหน้าหลัก
4. ถ้าถูก เครื่องจักรทำงาน มี animation, SFX และรางวัล
5. ถ้าผิด พิกซ์แสดงการจัดกลุ่มแบบย่อ ให้ผู้เล่นแก้ใหม่
6. สรุปความก้าวหน้าเป็นชิ้นส่วน/ตรา/คู่คูณที่คล่องขึ้น

## โหมด

- **Story Mission** ภารกิจมีบทสนทนาและฉากเมือง
- **Free Workshop** ทดลองจัดกลุ่มโดยไม่มีแรงกดดันด้านเวลา
- **Signal Hunt** ทบทวนคู่คูณที่ระบบพบว่ายังไม่มั่นใจ

## การจบรอบ

ทุกภารกิจต้องมี explicit result state: success, retry, pause, time-up หรือ quit. ห้ามปล่อยให้ scene นิ่งโดยไม่มีข้อความหรือ action ต่อไป
