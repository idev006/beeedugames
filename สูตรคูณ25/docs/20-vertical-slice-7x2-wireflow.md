# Vertical Slice Wireflow: ภารกิจ 7 × 2

## Learning intent

ผู้เรียนต้องเข้าใจว่า `7 × 2` หมายถึง 7 กลุ่มที่เท่ากัน กลุ่มละ 2 และผลรวมเกิดจากการบวก 2 ซ้ำ 7 ครั้ง

## Player-facing flow

```text
รับภารกิจ: ไฟเมืองต้องการ 7 กลุ่ม กลุ่มละ 2 ดวง
  -> เห็นแท่นพลัง 7 แท่น แท่นละมีช่อง 2 ดวง
  -> แตะ/คลิกแท่นเพื่อชาร์จทีละกลุ่ม
  -> กลุ่มที่ชาร์จแล้วสว่างและล็อกจำนวน 2 ดวง
  -> ครบ 7 กลุ่ม แสดงการบวกซ้ำ 2 + 2 + 2 + 2 + 2 + 2 + 2
  -> เปิดแกนคำตอบและให้เลือกผลรวม 14
  -> แกนพลังทำงาน เมืองสว่าง และมอบรางวัล
```

## State flow

```text
round:ready
  -> group-building
  -> group-building (n/7)
  -> group-complete
  -> answer-ready
  -> answer-feedback
  -> round:new หรือ game:finish
```

## Rules

- การชาร์จแท่นไม่เปลี่ยนคะแนนหรือหัวใจ
- แท่นหนึ่งครั้งแทนหนึ่งกลุ่ม ไม่สร้างกลุ่มซ้ำเมื่อแตะซ้ำ
- คำตอบจะ submit ได้เมื่อครบทุกกลุ่ม
- การเลือก answer core ยังคงผ่าน `GameStore.submit()`
- หากตอบผิด กลุ่มพลังงานยังคงอยู่เพื่อให้เด็กย้อนกลับไปตรวจสอบ
- การเริ่ม round ใหม่ต้อง reset group progress และ answer lock

## Feedback copy

| State | Message |
|---|---|
| เริ่มภารกิจ | `ชาร์จ 7 แท่น แท่นละ 2 ดวง` |
| กำลังสร้างกลุ่ม | `ชาร์จแล้ว 3 จาก 7 กลุ่ม` |
| ครบกลุ่ม | `ครบ 7 กลุ่มแล้ว ลองรวมพลังทั้งหมด` |
| คำตอบผิดครั้งแรก | `ลองดูอีกครั้ง: มี 7 กลุ่ม กลุ่มละ 2 ดวง` |
| คำตอบผิดซ้ำ | `การบวกซ้ำคือ 2 เพิ่มขึ้น 7 ครั้ง รวมเป็น 14` |
| สำเร็จ | `7 กลุ่ม × กลุ่มละ 2 = 14` |

## Acceptance criteria

- ผู้เล่นเห็นและชาร์จได้ครบ 7 แท่น
- แต่ละแท่นแสดงจำนวนต่อกลุ่มเป็น 2 อย่างชัดเจน
- answer core ถูกล็อกจนกว่าจะครบ 7 กลุ่ม
- การชาร์จแท่นไม่ทำให้หัวใจหรือคะแนนเปลี่ยน
- หลังครบกลุ่ม คำตอบที่ถูกต้องคือ 14 และ submit ผ่าน GameStore
- ตอบผิดแล้วกลับไปตรวจกลุ่มได้โดยไม่ล้างความก้าวหน้าของการสร้างกลุ่ม
- round ใหม่ล้าง progress เดิมและไม่เหลือ interactive object จาก round เก่า
