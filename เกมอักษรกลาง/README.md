# ป่าเห็ดอักษรกลาง

เกมการเรียนรู้ภาษาไทยสำหรับฝึกจำแนกอักษรกลางทั้ง 9 ตัว: ก จ ฎ ฏ ด ต บ ป อ

## วิธีเปิดเกม

ห้ามเปิด `index.html` ด้วยการดับเบิลคลิกเป็น `file://` เพราะเบราว์เซอร์จะบล็อก JavaScript module, การโหลด JSON และกล้อง AR

วิธีง่ายที่สุดบน Windows:

1. เปิด PowerShell ในโฟลเดอร์นี้
2. รัน `powershell -ExecutionPolicy Bypass -File .\start-local-server.ps1`
3. เปิด `http://localhost:8000/`

หรือใช้ VS Code Live Server / GitHub Pages ได้เช่นกัน การเปิดผ่าน `https://` หรือ `localhost` จะทำให้ JSON, Vue module และกล้อง AR ทำงานได้

## การควบคุม

- แตะ/คลิกเห็ดที่ตรงกับโจทย์
- กด `เปิดโหมด AR` เพื่อใช้กล้องและปลายนิ้วชี้เป็น pointer
- ในโหมด AR ให้ใช้นิ้วชี้เลื่อนไปที่เห็ด แล้วจีบนิ้วโป้งกับนิ้วชี้เพื่อเลือก
- หากเปิดกล้องไม่ได้ เกมยังเล่นด้วยการแตะหน้าจอหรือเมาส์ได้

## ข้อมูลเกม

แก้ไขอักษร, sprite index และด่านได้จากไฟล์ใน `data/` โดยไม่ต้องแก้ game loop หลัก
